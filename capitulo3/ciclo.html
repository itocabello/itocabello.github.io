3.2.3 Ciclo de vida Big Data Hadoop

Fases principales del tratamiento de los datos dentro de una arquitectura Big Data basada en Hadoop.

El ciclo de vida de un proyecto Big Data comprende un conjunto de etapas que permiten gestionar la información desde su adquisición hasta su almacenamiento, procesamiento y análisis.

En una arquitectura basada en Hadoop, estas fases se apoyan en diferentes componentes del ecosistema, permitiendo gestionar grandes volúmenes de información de forma distribuida.

Principales fases del ciclo de vida Big Data

En el contexto de este proyecto, el ciclo de vida de los datos puede organizarse en las siguientes etapas principales:

  1. Ingestión de datos: incorporación de información procedente de diferentes fuentes.
  2. Almacenamiento de datos: conservación de la información mediante sistemas adecuados al tipo y volumen de los datos.
  3. Procesamiento, análisis y consulta: tratamiento de la información almacenada para obtener resultados que puedan ser utilizados posteriormente.

1 Ingestión de datos

La ingestión de datos representa la etapa inicial del ciclo de vida del Big Data. En esta etapa los datos son ingeridos desde diferentes fuentes y almacenados en la base de datos o sistema que posteriormente permitirá consultarlos, transformarlos y analizarlos.

Las fuentes de datos pueden variar considerablemente e incluyen bases de datos, archivos, aplicaciones de negocio, dispositivos IoT, redes sociales, entre otras.

Objetivo de la ingestión

El objetivo de esta fase es incorporar los datos procedentes de las diferentes fuentes al entorno de procesamiento para que puedan ser almacenados y tratados posteriormente.

Para revisar las tecnologías más utilizadas en la ingestión o inyección de datos, consultar el apartado 3.6.1 - Inyección de datos.

2 Almacenamiento de datos (Data Storage)

El almacenamiento de Big Data depende principalmente del formato de los datos y de las características del sistema utilizado para su gestión.

Los datos estructurados son almacenados habitualmente en sistemas de administración de bases de datos relacionales.

Por otro lado, los datos semiestructurados y no estructurados pueden ser almacenados en sistemas de bases de datos conocidos como NoSQL.

Tipos de bases de datos NoSQL

Estos sistemas pueden clasificarse en diferentes categorías atendiendo a la forma en la que organizan y almacenan la información.

  • Bases de datos orientadas a documentos.
  • Bases de datos orientadas a columnas.
  • Bases de datos basadas en grafos.
  • Bases de datos clave-valor.

En el ecosistema Hadoop, el almacenamiento distribuido constituye una parte fundamental de la arquitectura, permitiendo conservar grandes cantidades de información para su posterior procesamiento.

3 Procesamiento, análisis y consulta de datos

Los datos recolectados en las fases anteriores serán procesados en este paso.

En esta etapa, el sistema de procesamiento de la canalización de datos puede enrutar los datos hacia diferentes destinos, clasificar el flujo de información y realizar las primeras operaciones de análisis.

Esta es también la capa donde se ejecutan las consultas (queries) y los procesos de análisis sobre los datos almacenados.

Procesamiento fuera de línea

Para análisis fuera de línea se puede utilizar un sistema de procesamiento por lotes, permitiendo trabajar con grandes volúmenes de información almacenada.

Apache Hive

Apache Hive es una infraestructura de almacenamiento de datos construida sobre Hadoop para proporcionar funcionalidades de agrupación, consulta y análisis de datos.

Apache Hive soporta el análisis de grandes conjuntos de datos almacenados bajo HDFS de Hadoop y en sistemas compatibles como el sistema de archivos Amazon S3.

Hive se ejecuta en el entorno Hadoop y permite transformar consultas expresadas mediante un lenguaje similar a SQL en procesos de procesamiento sobre los datos almacenados en el clúster.

Hive Query Language

Para realizar las consultas, Hive proporciona un lenguaje propio denominado Hive Query Language (HQL), también denominado HiveQL.

Su sintaxis está basada en SQL y facilita la lectura, escritura y administración de grandes conjuntos de datos almacenados en sistemas distribuidos.

El software de almacenamiento de datos Apache Hive facilita la lectura, escritura y administración de grandes conjuntos de datos que residen en almacenamiento distribuido mediante SQL.

Hive proporciona una herramienta de línea de comandos y un controlador JDBC que permite conectar a los usuarios con el sistema.

De esta forma, Hive proporciona un mecanismo para estructurar los datos almacenados en Hadoop y realizar consultas mediante un lenguaje basado en SQL.

Aplicación en el proyecto

Las fases descritas forman parte de la arquitectura Big Data desarrollada en este proyecto. Los datos procedentes de las diferentes fuentes son incorporados al entorno Hadoop, almacenados de forma distribuida y posteriormente procesados mediante las herramientas disponibles en el ecosistema.

Esta organización permite al estudiante comprender el recorrido de los datos desde su incorporación al sistema hasta su procesamiento y consulta, relacionando los conceptos teóricos del ciclo de vida Big Data con los ejercicios prácticos desarrollados posteriormente.

Conclusión

El ciclo de vida Big Data permite organizar las diferentes etapas por las que atraviesa la información dentro de una arquitectura de datos.

En el entorno Hadoop utilizado en este proyecto, estas etapas permiten relacionar la ingestión de los datos con su almacenamiento distribuido y con las herramientas utilizadas posteriormente para su procesamiento, análisis y consulta.
