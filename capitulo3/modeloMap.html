3.1 Modelo de programación MapReduce mediante Hadoop Streaming

Como ya hemos visto en el punto anterior, la principal ventaja de MapReduce es que abstrae la complejidad inherente a los sistemas distribuidos, permitiendo que el desarrollador se centre en la lógica de procesamiento mientras Hadoop gestiona aspectos como la distribución de tareas, la tolerancia a fallos, la comunicación entre nodos y la optimización de recursos.

Hadoop Streaming

Dentro del ecosistema Hadoop, una de las alternativas más flexibles para implementar aplicaciones MapReduce es Hadoop Streaming. Esta herramienta permite desarrollar programas MapReduce utilizando cualquier lenguaje de programación capaz de leer datos desde la entrada estándar (stdin) y escribir resultados en la salida estándar (stdout).

Gracias a esta característica, es posible implementar procesos de análisis utilizando lenguajes ampliamente conocidos como Python, sin necesidad de desarrollar código en Java, lenguaje nativo de Hadoop.

Funcionamiento de Hadoop Streaming

El funcionamiento de Hadoop Streaming consiste en ejecutar programas externos como procesos Mapper y Reducer. Hadoop proporciona automáticamente los datos de entrada a dichos programas y recoge sus resultados para continuar con el flujo de procesamiento distribuido.

De esta forma, se mantiene toda la potencia del modelo MapReduce mientras se simplifica considerablemente el desarrollo de aplicaciones.

Mapper

El programa Mapper recibe los datos de entrada y transforma cada registro en pares clave-valor que serán procesados posteriormente por Hadoop.

Reducer

El programa Reducer recibe los datos agrupados por Hadoop y realiza las operaciones necesarias para obtener el resultado final del procesamiento.

Ventajas de Hadoop Streaming

La utilización de Hadoop Streaming presenta numerosas ventajas en entornos formativos y de experimentación.

  • Reduce la complejidad de aprendizaje asociada al desarrollo de aplicaciones MapReduce tradicionales en Java.
  • Permite utilizar lenguajes de programación conocidos, como Python.
  • Facilita el diseño, implementación y prueba de algoritmos sobre grandes conjuntos de datos.
  • Permite centrarse en la comprensión de los principios fundamentales del procesamiento distribuido.

Aplicación en el proyecto

En nuestro proyecto, Hadoop Streaming se emplea como mecanismo para explotar las capacidades del modelo MapReduce mediante programas desarrollados en Python.

Esta aproximación permite analizar de forma práctica el funcionamiento interno de las fases Map y Reduce, comprender el flujo de datos dentro de una arquitectura distribuida y adquirir experiencia en el desarrollo de soluciones Big Data utilizando herramientas ampliamente utilizadas en entornos profesionales.

Ejemplo de ejecución mediante Hadoop Streaming

A continuación se muestra un ejemplo visual del funcionamiento de Hadoop Streaming. Para ejecutar un trabajo MapReduce se puede utilizar una orden como la siguiente:

hadoop jar hadoop-streaming.jar \
  -input /entrada.txt \
  -output salida \
  -mapper map.py \
  -reducer reduce.py

Mediante esta instrucción se indica a Hadoop el fichero de entrada, el directorio donde se almacenará el resultado y los programas que actuarán como Mapper y Reducer.

Parámetro Función
-input Define la ubicación de los datos de entrada.
-output Define el directorio donde Hadoop almacenará los resultados.
-mapper Especifica el programa que realizará la fase Map.
-reducer Especifica el programa que realizará la fase Reduce.

Flujo del procesamiento

1. Datos de entrada

Hadoop recibe los datos especificados mediante el parámetro -input.

2. Fase Map

El programa indicado mediante -mapper procesa los datos y genera los pares clave-valor intermedios.

3. Shuffle y agrupación

Hadoop agrupa y distribuye automáticamente los resultados intermedios generados por los Mapper.

4. Fase Reduce

El programa indicado mediante -reducer procesa los datos agrupados y genera el resultado final.

5. Resultado

Hadoop almacena los resultados en el directorio indicado mediante el parámetro -output.

Conclusión

Hadoop Streaming proporciona una forma sencilla y flexible de implementar el modelo MapReduce utilizando programas externos desarrollados en lenguajes como Python. En el contexto de este proyecto, esta herramienta facilita que el estudiante pueda experimentar directamente con las fases de procesamiento distribuido y comprender cómo Hadoop coordina el trabajo entre los diferentes componentes del clúster.
