3.3 Instalación de Docker y Docker Compose

Como paso previo al despliegue de la infraestructura Big Data, es necesario preparar el entorno de ejecución mediante la instalación de Docker Engine y Docker Compose, herramientas encargadas de la creación, administración y orquestación de los contenedores que forman el clúster Hadoop.

En este proyecto, Docker proporciona el motor de virtualización ligera sobre el que se ejecutan todos los servicios, mientras que Docker Compose permite definir la infraestructura completa mediante un único archivo docker-compose.yml, simplificando el despliegue y la gestión del entorno distribuido.

El fichero docker-compose.yml utilizado durante el desarrollo del proyecto puede descargarse desde el repositorio GitHub del proyecto para reproducir el despliegue completo del clúster Hadoop.

Instalación de Docker Engine

Una vez instalado Ubuntu 22.04, se actualizan los repositorios del sistema y se instalan Docker Engine y los servicios necesarios para su ejecución automática.

Comandos de instalación 
sudo apt update
sudo apt install -y docker.io
sudo systemctl enable docker
sudo systemctl start docker

Verificación de la instalación

Una vez finalizada la instalación, es recomendable comprobar que Docker se ha instalado correctamente verificando la versión disponible en el sistema.

Comandos de comprobación 
docker --version
docker compose version

Resultado

Tras completar este proceso, el sistema queda preparado para descargar las imágenes Docker del proyecto y desplegar automáticamente toda la infraestructura Hadoop mediante Docker Compose.

YarnManager Gestión de recursos YARN.

Publicación de puertos

Docker Compose publica automáticamente los puertos necesarios para acceder a los servicios Hadoop desde el sistema anfitrión.

Servicio Puerto Descripción
NameNode 9870 Interfaz Web HDFS.
YARN 8088 Resource Manager.
Jupyter Notebook 8888 Entorno de prácticas.
Hive 10000 Servidor Hive.

Volúmenes persistentes

Con el objetivo de garantizar la persistencia de la información, Docker Compose utiliza volúmenes compartidos entre el sistema anfitrión y los contenedores.

Gracias a estos volúmenes, los datos permanecen almacenados incluso cuando los contenedores son eliminados o recreados.

Información almacenada
  • Datos HDFS.
  • Scripts Python.
  • Programas MapReduce.
  • Datasets.
  • Resultados de procesamiento.
  • Archivos de configuración.

Directorio compartido

Para facilitar el intercambio de información entre el sistema anfitrión y el clúster Hadoop, se utiliza el directorio compartido: 

                /media/notebooks

Todo archivo copiado en este directorio queda disponible automáticamente dentro del contenedor NameNode, pudiendo ser procesado mediante HDFS, MapReduce, Hadoop Streaming o Hive.

Ventajas de Docker Compose

Despliegue
  • Un único archivo YAML.
  • Despliegue mediante un solo comando.
  • Configuración reproducible.
  • Inicio automático de servicios.
Administración
  • Escalabilidad sencilla.
  • Persistencia mediante volúmenes.
  • Red privada automática.
  • Infraestructura portable.

Conclusión

Docker Compose constituye el elemento central del despliegue de la infraestructura Big Data desarrollada en este proyecto. Mediante una única definición declarativa es posible construir, configurar y ejecutar un clúster Hadoop completamente funcional, integrando NameNode, DataNodes, YARN, Hive, Jupyter Notebook y el resto de componentes necesarios para el desarrollo de las prácticas.

El archivo completo utilizado para este despliegue puede consultarse en el Anexo Docker, apartado docker-compose.yml.
