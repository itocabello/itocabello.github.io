Lección 5. Serialización y deserialización de los datos

Formatos de almacenamiento para arquitecturas Big Data

Introducción

Cualquier arquitectura de datos Big Data requiere que los datos estén organizados correctamente tanto para procesamiento como para almacenamiento. Esto se alcanza mediante una infraestructura que lleva las características de los datos desde su representación inicial hasta la versión optimizada para almacenamiento o distribución.

Este proceso se denomina serialización; su operación contraria es la deserialización.

En el ecosistema de Hadoop, estos procesos se utilizan para cambiar la información entre los distintos elementos de la arquitectura, mejorar el uso del almacenamiento distribuido y aumentar el rendimiento de las tareas de procesamiento.

La utilización de formatos estándar redunda en un menor consumo de almacenamiento por disco y en un menor tráfico de datos entre nodos mientras se ejecutan las aplicaciones distribuidas.

Formatos de datos en Big Data

Los formatos más frecuentes utilizados en plataformas de Big Data son Apache Avro y Apache Parquet.

Estos formatos permiten organizar la información de manera adecuada para su almacenamiento y posterior procesamiento dentro del ecosistema Hadoop.

Apache Avro

Formato de serialización utilizado en arquitecturas Big Data para organizar y almacenar información de forma adecuada para su procesamiento distribuido.

Apache Parquet

Formato utilizado en plataformas Big Data para optimizar el almacenamiento y facilitar el procesamiento de los conjuntos de datos.

Ejercicios prácticos

Además de los contenidos teóricos, se llevarán a cabo ejercicios prácticos empleando conjuntos de datos presentes a lo largo de la presente investigación.

El objetivo es que el estudiante pueda percibir la efectividad de estos formatos al almacenarse y procesarse en un entorno distribuido.

Actividad práctica

Los ejercicios permitirán preparar conjuntos de datos para su posterior explotación mediante Hadoop Streaming y otras herramientas del ecosistema Hadoop.

Relación con el Capítulo 3

El contenido desarrollado en esta lección se apoya directamente en el Capítulo 3 de la memoria, donde se describen en detalle los principales componentes que forman parte del ecosistema Hadoop.

Durante este módulo el estudiante relacionará la teoría estudiada con la infraestructura desplegada mediante Docker, observando cómo cada uno de los servicios implementados participa en el funcionamiento del clúster distribuido.

HDFS

Sistema de archivos distribuido encargado de almacenar los bloques de datos entre los distintos DataNodes del clúster.

YARN

Administrador de recursos responsable de coordinar la ejecución de tareas distribuidas y asignar recursos a las aplicaciones.

MapReduce

Modelo de programación encargado de dividir el procesamiento en tareas paralelas que posteriormente serán combinadas para obtener el resultado final.

Aplicación práctica dentro del proyecto

A diferencia de un estudio exclusivamente teórico, todos los conceptos tratados durante esta lección podrán observarse directamente sobre el clúster Hadoop desplegado en este proyecto.

Los servicios ejecutados mediante contenedores Docker permiten reproducir un entorno distribuido real donde los distintos nodos cooperan para almacenar, gestionar y procesar información utilizando las tecnologías propias del ecosistema Hadoop.

Durante las siguientes prácticas el estudiante utilizará este mismo clúster para ejecutar programas MapReduce, almacenar datos en HDFS, administrar los recursos mediante YARN y analizar información utilizando Apache Hive.

Contenidos que se abordarán

  • Arquitectura del ecosistema Hadoop.
  • Funcionamiento de HDFS.
  • Gestión de recursos mediante YARN.
  • Modelo de programación MapReduce.
  • Escalabilidad y tolerancia a fallos.
  • Relación entre la teoría y el clúster Docker del proyecto.

Conclusión

Esta lección constituye el enlace entre los fundamentos teóricos estudiados en el Capítulo 3 y su aplicación práctica dentro de la infraestructura Big Data desarrollada durante el proyecto.

Al finalizar el estudio de este módulo, el estudiante comprenderá la función de los principales componentes del ecosistema Hadoop y estará preparado para utilizar el clúster desplegado mediante Docker en las siguientes actividades prácticas del curso.
