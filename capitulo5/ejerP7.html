Ejercicio Final 2: Levantar contenedor db_cluster – MySQL¡

Despliegue de MySQL para la explotación de los datos generados durante el procesamiento Hadoop.

Objetivo del ejercicio

El ejercicio tiene como finalidad aplicar un proceso de anonimización sobre los documentos clínicos de MEDDOCAN, procesarlos mediante Python 3 y Hadoop Streaming, generar un fichero estructurado en formato CSV y prepararlo posteriormente para su incorporación a una base de datos MySQL.

Una vez finalizados los procesos de procesamiento y transformación de los datos mediante el clúster Hadoop, se puede utilizar un contenedor independiente para almacenar y explotar los resultados mediante una base de datos relacional.

En este ejercicio se propone levantar el contenedor db_cluster, basado en MySQL, utilizando los ficheros .csv generados durante las etapas anteriores del proyecto.

El objetivo es completar el flujo de procesamiento de los datos, desde su generación en el clúster Hadoop hasta su almacenamiento estructurado en una base de datos MySQL.

Arquitectura del despliegue

La siguiente figura muestra la arquitectura que será desplegada cuando sea necesario utilizar un contenedor con MySQL y realizar la carga de los datos compartidos en formato .csv.

1. Traslado del fichero CSV

Lo primero que debemos realizar antes de levantar el contenedor db_cluster es trasladar los datos del fichero .csv generado por el clúster Hadoop.

El fichero se encuentra inicialmente en el directorio compartido:

/media/notebook

Este fichero deberá copiarse al directorio utilizado por db_cluster para realizar la carga de los datos:

/home/uned/ClusterUned/db_cluster/dataset
Objetivo

El fichero CSV debe estar disponible en el directorio dataset antes de realizar la construcción de la imagen Docker.

2. Compilación de la imagen Docker

Antes de levantar el contenedor db_cluster, es necesario compilar la imagen que utilizará el contenedor para cargar los datos CSV.

Para ello, debemos situarnos en el directorio donde se encuentra el Dockerfile correspondiente a db_cluster y ejecutar el siguiente comando:

sudo docker build -t db_cluster .

El comando anterior construye la imagen Docker denominada db_cluster utilizando como referencia el Dockerfile disponible en el directorio actual.
