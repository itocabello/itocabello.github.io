Ejercicio Final 2: Levantar contenedor db_cluster – MySQL¡

Despliegue de MySQL para la explotación de los datos generados durante el procesamiento Hadoop.

Objetivo del ejercicio

En este ejercicio se propone levantar el contenedor db_cluster, basado en MySQL, utilizando los ficheros .csv generados durante las etapas anteriores del proyecto.

El objetivo es completar el flujo de procesamiento de los datos, desde su generación en el clúster Hadoop hasta su almacenamiento estructurado en una base de datos MySQL.

1. Traslado del fichero CSV

Lo primero que debemos realizar antes de levantar el contenedor db_cluster es trasladar los datos del fichero .csv generado por el clúster Hadoop.

El fichero se encuentra inicialmente en el directorio compartido:

/media/notebook

Este fichero deberá copiarse al directorio utilizado por db_cluster para realizar la carga de los datos:

/home/uned/ClusterUned/db_cluster/dataset
Objetivo

El fichero CSV debe estar disponible en el directorio dataset antes de realizar la construcción de la imagen Docker.

2. Compilación de la imagen Docker

Antes de levantar el contenedor db_cluster, es necesario compilar la imagen que utilizará el contenedor para cargar los datos CSV.

Para ello, debemos situarnos en el directorio donde se encuentra el Dockerfile correspondiente a db_cluster y ejecutar el siguiente comando:

sudo docker build -t db_cluster .

El comando anterior construye la imagen Docker denominada db_cluster utilizando como referencia el Dockerfile disponible en el directorio actual.

Importante

Cualquier cambio que el estudiante realice en el fichero init.sql o en la carga de los ficheros .csv requerirá volver a realizar el proceso de compilación de la imagen Docker.

3. Levantar el contenedor db_cluster

Una vez compilada la imagen, ya podremos levantar el contenedor para realizar la carga automática de los datos.

Para ello debemos ubicarnos en el directorio raíz del proyecto:

/home/uned/ClusterUned

A continuación, se ejecutará el fichero docker-compose-dbcluster.yaml mediante el siguiente comando:

sudo docker-compose -f docker-compose-dbcluster.yaml up -d

La opción -d permite ejecutar el contenedor en segundo plano.

Resultado esperado

4. Comprobar los registros del contenedor

Una vez levantado el contenedor, podemos comprobar si se ha producido algún error durante su inicialización o durante la carga de los datos.

Para consultar los registros del contenedor se ejecutará:

sudo docker logs db_cluster

La información mostrada permitirá comprobar el estado del proceso de inicialización y detectar posibles errores durante la carga de los datos.

5. Acceso al servidor MySQL

Para acceder al servidor MySQL que se encuentra ejecutándose dentro del contenedor, se utilizará la siguiente sentencia:

sudo docker-compose -f docker-compose-dbcluster.yaml exec db mysql -uroot -p

Al ejecutar el comando, MySQL solicitará la contraseña del usuario root.

Contraseña: uned

6. Seleccionar la base de datos

Una vez dentro del cliente de MySQL, será necesario indicar la base de datos que se desea utilizar.

use mydatabase;

A partir de este momento será posible acceder a las tablas almacenadas en la base de datos y consultar la información cargada.

7. Comprobación de los datos cargados

Una vez seleccionada la base de datos mydatabase, ya es posible acceder a los datos y a las tablas cargadas durante el proceso de inicialización.

En este ejercicio, se ha cargado la tabla Corpus_Meddocan utilizando los datos procedentes del fichero .csv generado en etapas anteriores.

Tabla: Corpus_Meddocan

A partir de este momento, los datos quedan disponibles para su consulta y posterior explotación mediante las herramientas proporcionadas por MySQL.

Propuesta de experimentación

Las características de la base de datos creada como prueba pueden modificarse para que el estudiante pueda experimentar con el funcionamiento de MySQL y comprobar los efectos de las diferentes modificaciones.

Se propone realizar, entre otras, las siguientes modificaciones:

  • Cambiar el nombre de la tabla.
  • Modificar los tipos de datos.
  • Añadir nuevos campos.
  • Crear nuevas tablas.
  • Realizar consultas sobre los datos almacenados.
  • Analizar los datos procedentes del corpus MEDDOCAN.

Conclusión

En este ejercicio se ha completado el proceso de despliegue del contenedor db_cluster utilizando MySQL como sistema de gestión de bases de datos.

Los datos generados previamente mediante el procesamiento del clúster Hadoop son trasladados al directorio utilizado por el contenedor, incorporados a la imagen Docker y posteriormente cargados en la base de datos.

En el caso desarrollado en este proyecto, la información anonimizada del corpus MEDDOCAN se almacena en la tabla Corpus_Meddocan de la base de datos mydatabase.

De esta forma, el estudiante puede observar el flujo completo de los datos, desde su procesamiento mediante Hadoop hasta su almacenamiento estructurado en una base de datos MySQL.
