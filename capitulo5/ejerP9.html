5.9.1. Ejercicio práctico con Apache Hive

Análisis de datos de calidad del aire mediante HiveQL

Ejercicio práctico con Apache Hive

En este ejercicio se propone utilizar Apache Hive para realizar consultas sobre un conjunto de datos abiertos correspondiente a la calidad del aire de Madrid.

El objetivo es aplicar los conocimientos adquiridos sobre el ecosistema Hadoop, especialmente sobre HDFS, Hive y el lenguaje de consultas HiveQL, utilizando un conjunto de datos real procedente de una fuente de datos abiertos.

El fichero de datos será descargado inicialmente desde el entorno Jupyter Notebook y almacenado en el volumen compartido utilizado por el clúster. Posteriormente, será incorporado al sistema de archivos distribuido HDFS para poder ser consultado mediante Apache Hive.

Objetivo del ejercicio

El objetivo principal consiste en familiarizar al estudiante con el proceso completo de incorporación de un conjunto de datos externo a Hadoop y su posterior explotación mediante consultas HiveQL.

Durante el ejercicio se trabajará con las diferentes fases del proceso: descarga del fichero, almacenamiento en HDFS, creación de la tabla externa y realización de consultas sobre los datos.

1. Conexión con Apache Hive mediante Beeline

La creación y gestión de las tablas Hive se realizará mediante el cliente Beeline, conectado al servicio HiveServer2.

Para establecer la conexión se ejecuta desde el contenedor correspondiente:

beeline -u jdbc:hive2://localhost:10000

Si la conexión se establece correctamente, Beeline muestra información relativa a la versión de Apache Hive y queda disponible el intérprete de comandos HiveQL.

Figura XX. Conexión con Apache Hive mediante el cliente Beeline. Fuente: elaboración propia.

2. Selección de la base de datos

Una vez establecida la conexión con Hive, se selecciona la base de datos que será utilizada para realizar el ejercicio.

USE healthcare;

A partir de este momento, las tablas creadas mediante HiveQL quedarán asociadas a la base de datos seleccionada.

3. Incorporación del conjunto de datos

El conjunto de datos utilizado corresponde a información de calidad del aire de Madrid. El fichero CSV será descargado inicialmente desde Jupyter y posteriormente almacenado en HDFS.

Para mantener la separación entre el almacenamiento local y el almacenamiento distribuido, el fichero se guardará inicialmente en el volumen compartido:

/media/notebooks/calidad_aire_madrid.csv

4. Almacenamiento del fichero en HDFS

Una vez disponible el fichero CSV en el volumen compartido, se crea un directorio específico dentro de HDFS para almacenar los datos.

hdfs dfs -mkdir -p /dataset/calidad_aire_madrid

Posteriormente se copia el fichero desde el sistema de archivos local al directorio creado:

hdfs dfs -put /media/notebooks/calidad_aire_madrid.csv /dataset/calidad_aire_madrid/

Finalmente, se comprueba que el fichero se encuentra disponible en HDFS:

hdfs dfs -ls /dataset/calidad_aire_madrid

5. Creación de la tabla externa en Hive

Una vez almacenado el fichero en HDFS, se crea una tabla externa en Hive mediante el cliente Beeline.

La utilización de una tabla externa permite que Hive mantenga la definición de la estructura de los datos sin asumir la gestión física del fichero original almacenado en HDFS.

La definición definitiva de la tabla deberá adaptarse a las columnas existentes en el fichero CSV descargado.

CREATE EXTERNAL TABLE IF NOT EXISTS calidad_aire_madrid (
    ...
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ';'
STORED AS TEXTFILE
LOCATION '/dataset/calidad_aire_madrid';

6. Comprobación de la tabla

Una vez creada la tabla, se puede comprobar su existencia mediante HiveQL:

SHOW TABLES;

También es posible consultar la estructura de la tabla:

DESCRIBE calidad_aire_madrid;

7. Consulta de los datos

Para comprobar que Hive puede acceder correctamente a la información almacenada en HDFS, se realiza una primera consulta sobre la tabla.

SELECT *
FROM calidad_aire_madrid
LIMIT 10;

Esta consulta permite comprobar que los registros del fichero CSV han sido interpretados correctamente por Hive.

8. Análisis de los datos mediante HiveQL

Una vez comprobada la correcta lectura de los datos, el estudiante puede realizar diferentes consultas de análisis utilizando las capacidades de HiveQL.

Consulta 1. Número de registros.
SELECT COUNT(*)
FROM calidad_aire_madrid;
Consulta 2. Agrupación de los datos.
SELECT ...
FROM calidad_aire_madrid
GROUP BY ...;
Consulta 3. Cálculo de valores medios.
SELECT ..., AVG(...)
FROM calidad_aire_madrid
GROUP BY ...;

Relación con el procesamiento distribuido

Este ejercicio permite observar cómo Apache Hive proporciona una capa de consulta de alto nivel sobre los datos almacenados en HDFS.

El estudiante utiliza HiveQL para expresar las consultas, mientras que Hive se encarga de generar el plan de ejecución correspondiente y utilizar los recursos disponibles en el ecosistema Hadoop para procesar la información.

Conclusión

El ejercicio permite completar el ciclo de explotación de un conjunto de datos abiertos dentro de la infraestructura Big Data desarrollada en el proyecto. El fichero de calidad del aire es descargado inicialmente desde Jupyter, almacenado en HDFS y posteriormente consultado mediante Apache Hive.

De esta forma, el estudiante puede comprobar cómo una fuente de datos externa puede incorporarse al ecosistema Hadoop y ser posteriormente explotada mediante consultas HiveQL sin necesidad de implementar directamente programas MapReduce.
