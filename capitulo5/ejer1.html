Ejercicio resuelto con Hadoop Streaming

Si continuamos con los ejemplos prácticos propuestos para realizar por parte del estudiante de una forma ordenada, en el ejercicio del punto 5.3.1, hemos cargado en HDFS los ficheros .txt con los cuales queremos comprender el funcionamiento del modelo MapReduce.

En esta práctica se ejecuta una tarea de MapReduce basada en un documento médico perteneciente al corpus MEDDOCAN. La finalidad es enseñar al estudiante cómo funciona la programación distribuida y facilitar su familiarización con los diferentes elementos que intervienen en un trabajo Hadoop.

Para ello se utilizan dos scripts desarrollados en Python, que actúan respectivamente como Mapper y Reducer. Estos programas serán ejecutados mediante Hadoop Streaming desde el entorno de trabajo utilizado durante el proyecto.

Objetivo del ejercicio

El objetivo del ejercicio consiste en cargar un archivo de texto en HDFS y, mediante Hadoop Streaming, lanzar los scripts desarrollados en Python para realizar un contador de palabras.

  • Cargar un fichero .txt del corpus MEDDOCAN en HDFS.
  • Ejecutar Hadoop Streaming desde Jupyter Notebook.
  • Utilizar un programa Python como Mapper.
  • Utilizar un programa Python como Reducer.
  • Comprender las fases Map, Shuffle y Reduce.
  • Obtener el número de apariciones de cada palabra del documento.

Funcionamiento del ejercicio

El ejercicio parte de un fichero de texto almacenado previamente en el sistema de archivos distribuido HDFS. Sobre este fichero se ejecuta un trabajo de procesamiento distribuido utilizando Hadoop Streaming.

Durante la ejecución, Hadoop procesa el contenido del documento mediante las diferentes fases del modelo MapReduce.

Map

El Mapper lee las líneas del documento y genera pares clave-valor.

(palabra, 1)

Shuffle

Hadoop agrupa automáticamente los pares generados por el Mapper según su clave.

palabra → [1,1,1,1...]

Reduce

El Reducer suma los valores asociados a cada palabra para obtener su frecuencia.

palabra → total

Programas utilizados

Para realizar el procesamiento se utilizan dos programas escritos en Python, que son proporcionados a Hadoop Streaming mediante la línea de comandos.

mapper.py

El programa Mapper se encarga de leer el contenido del documento y generar un par clave-valor por cada palabra encontrada. 

palabra    1
palabra    1
palabra    1
reducer.py

El Reducer recibe las palabras agrupadas y realiza la suma de sus apariciones. 

palabra    5
hadoop     8
datos      12

Ejecución mediante Hadoop Streaming

Una vez preparados los programas mapper.py y reducer.py, se ejecuta el trabajo utilizando Hadoop Streaming.

La ejecución se realiza desde Jupyter Notebook, utilizando la terminal disponible en el entorno del proyecto. 
hadoop jar /usr/local/hadoop/share/hadoop/tools/lib/hadoop-streaming-3.4.0.jar \
-files mapper.py,reducer.py \
-mapper mapper.py \
-reducer reducer.py \
-input /datasets/MEDDOCAN \
-output /datasets/wordcount

Secuencia de ejecución

El funcionamiento completo del ejercicio puede resumirse en las siguientes etapas:

  1. Se dispone de un documento .txt perteneciente al corpus MEDDOCAN.
  2. El documento se encuentra almacenado en HDFS.
  3. Hadoop Streaming inicia el trabajo MapReduce.
  4. El Mapper lee el documento y genera los pares (palabra, 1).
  5. Hadoop realiza automáticamente la fase Shuffle, agrupando las claves iguales.
  6. El Reducer suma los valores de cada palabra.
  7. El resultado se almacena nuevamente en HDFS.
  8. Finalmente, el estudiante puede consultar el resultado obtenido.

Resultado del ejercicio

Como resultado del procesamiento se obtiene un listado de términos junto con el número de veces que aparecen en el documento utilizado como entrada.

De esta forma, el estudiante puede comprobar de manera práctica cómo un documento almacenado en HDFS es procesado mediante un trabajo distribuido de MapReduce utilizando Hadoop Streaming.
