Dataset clínico sintético: Synthea™

Para la recogida de datos se utilizará el conjunto de datos sintéticos generado mediante Synthea™, una herramienta de código abierto ampliamente utilizada en investigación, docencia y desarrollo de aplicaciones sanitarias.

Synthea™ genera pacientes virtuales completos con historiales clínicos realistas, evitando los problemas derivados de la utilización de datos médicos reales y garantizando la privacidad de la información.

Synthea™ permite generar automáticamente información clínica estructurada que incluye datos demográficos, diagnósticos, procedimientos médicos, tratamientos, medicación, episodios clínicos y evolución temporal de cada paciente. Gracias a ello es posible disponer de un conjunto de datos con características muy similares a las historias clínicas reales, manteniendo la confidencialidad de la información sanitaria.

Los datos generados serán utilizados como base para el procesamiento distribuido dentro del clúster Hadoop desarrollado en este proyecto, almacenándose inicialmente en formato CSV para posteriormente ser procesados mediante tecnologías como HDFS, MapReduce, Hive y Parquet.

¿Por qué utilizar Synthea?

Privacidad

No contiene información sanitaria real.

Pacientes virtuales

Generación automática de historiales clínicos completos.

Big Data

Compatible con Hadoop, Hive, Spark y otros sistemas distribuidos.

Reproducible

Ideal para investigación y entornos académicos.

Modelo de datos utilizado

El proyecto utiliza cuatro de las principales tablas generadas por Synthea™, las cuales constituyen el núcleo del procesamiento distribuido realizado durante las prácticas.

Tabla Descripción Uso en el proyecto
Patients Información demográfica y administrativa de los pacientes. Identificación y análisis de pacientes.
Organizations Hospitales, clínicas y centros sanitarios. Análisis geográfico y organizativo.
Providers Médicos y profesionales sanitarios. Relación entre pacientes y profesionales.
Encounters Consultas, ingresos y episodios clínicos. Procesamiento distribuido de actividad clínica.

Estructura de las tablas

Contiene la información demográfica, administrativa y socioeconómica de todos los pacientes generados por Synthea.

  • UUID del paciente
  • Fecha de nacimiento
  • Sexo
  • Estado civil
  • Dirección
  • Ciudad
  • Provincia
  • Código postal
  • Ingresos
  • Gastos sanitarios
  • Cobertura médica

Información correspondiente a hospitales, clínicas y organizaciones sanitarias.

  • Nombre del centro
  • Dirección
  • Ciudad
  • Estado
  • Teléfono
  • Ingresos
  • Nivel de utilización

Profesionales sanitarios asociados a las organizaciones.

  • Nombre
  • Apellidos
  • Especialidad
  • Género
  • Teléfono

Registra cada episodio clínico asociado a un paciente.

  • Paciente
  • Hospital
  • Médico responsable
  • Tipo de encuentro
  • Fecha inicio
  • Fecha fin
  • Motivo
  • Estado del episodio

Conclusión

El uso de Synthea™ proporciona un conjunto de datos clínicos completamente sintéticos, reproducibles y libres de restricciones de privacidad, constituyendo una base idónea para el desarrollo de prácticas de procesamiento distribuido mediante Hadoop, HDFS, MapReduce, Hive y Parquet dentro del entorno Big Data desarrollado en este proyecto.
