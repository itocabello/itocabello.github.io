Segundo ejercicio resuelto con Hadoop Streaming - Análisis de pacientes

En este Segundo ejercicio práctico se continúa con el procesamiento de los conjuntos de datos disponibles en el entorno Hadoop, utilizando en este caso el fichero patients.csv del conjunto de datos Synthea.

El fichero contiene información asociada a los pacientes y se encuentra previamente almacenado en HDFS. A partir de estos datos, se plantea una tarea de procesamiento distribuido que permite al estudiante aplicar los conceptos estudiados sobre el modelo de programación MapReduce.

Para desarrollar el ejercicio se han creado dos scripts en Python, mapper_pacientes.py y reducer_pacientes.py, que permiten realizar el procesamiento de los registros mediante Hadoop Streaming.

El Mapper se encarga de leer los datos de entrada y generar los pares clave-valor necesarios para el análisis, mientras que Hadoop realiza automáticamente las fases de Shuffle y Sort, agrupando los registros que presentan una misma clave. Finalmente, el Reducer procesa estos grupos y obtiene el número de pacientes correspondiente a cada combinación de género y década de nacimiento.

Objetivo del ejercicio

El objetivo del ejercicio consiste en procesar el fichero patients.csv almacenado en HDFS mediante Hadoop Streaming, utilizando Python para realizar una agrupación de los pacientes en función de su género y década de nacimiento.

  • Utilizar el fichero patients.csv del conjunto de datos Synthea.
  • Procesar los datos almacenados en HDFS.
  • Utilizar mapper_pacientes.py como programa Mapper.
  • Utilizar reducer_pacientes.py como programa Reducer.
  • Comprender las fases Map, Shuffle, Sort y Reduce.
  • Agrupar los pacientes por género y década de nacimiento.
  • Obtener el número de pacientes correspondiente a cada grupo.

Funcionamiento del ejercicio

El ejercicio parte del fichero patients.csv, almacenado previamente en el sistema de archivos distribuido HDFS. Sobre este fichero se ejecuta un trabajo de procesamiento distribuido utilizando Hadoop Streaming.

El procesamiento utiliza la información correspondiente a la fecha de nacimiento y al género de cada paciente. A partir de estos campos, el Mapper genera una clave que permite agrupar los pacientes según su década de nacimiento y género.

Map

El Mapper lee cada registro del fichero patients.csv y obtiene los datos necesarios para realizar la clasificación.

A partir de la fecha de nacimiento y del género genera un par clave-valor.

(década_genero, 1)

Shuffle y Sort

Hadoop agrupa automáticamente los pares generados por el Mapper según su clave.

De esta forma, todos los pacientes que pertenecen al mismo grupo son enviados al mismo Reducer.

grupo → [1,1,1,1...]

Reduce

El Reducer recibe los registros agrupados y suma los valores asociados a cada combinación de género y década.

grupo → total

Programas utilizados

Para realizar el procesamiento se utilizan dos programas escritos en Python, que son proporcionados a Hadoop Streaming mediante la línea de comandos.

mapper_pacientes.py

El programa Mapper se encarga de leer los registros del fichero de pacientes y generar una clave formada por la década de nacimiento y el género.

Para cada paciente se genera un valor inicial igual a 1, que posteriormente será utilizado por el Reducer para realizar el recuento. 

1980_M    1
1980_F    1
1990_F    1
1970_M    1
reducer_pacientes.py

El Reducer recibe las claves agrupadas por Hadoop y suma los valores asociados a cada grupo.

El resultado permite conocer el número de pacientes perteneciente a cada combinación de década de nacimiento y género. 

1970_M    125
1980_F    143
1980_M    137
1990_F    158

Ejecución mediante Hadoop Streaming

Una vez preparados los programas mapper_pacientes.py y reducer_pacientes.py, se ejecuta el trabajo utilizando Hadoop Streaming.

La ejecución se realiza desde Jupyter Notebook, utilizando el entorno Hadoop desplegado mediante contenedores. 
hadoop jar /usr/local/hadoop/share/hadoop/tools/lib/hadoop-streaming-3.4.0.jar \
-files mapper_pacientes.py,reducer_pacientes.py \
-mapper mapper_pacientes.py \
-reducer reducer_pacientes.py \
-input /datasets/synthea/csv/patients.csv \
-output /datasets/synthea/resultados/pacientes_genero_decada

Consulta del resultado

Una vez finalizada la ejecución del trabajo MapReduce, el resultado se encuentra almacenado en HDFS dentro del directorio de salida definido para el ejercicio.

Para comprobar los ficheros generados y consultar los resultados obtenidos se pueden utilizar los siguientes comandos: 

hdfs dfs -ls /datasets/synthea/resultados/pacientes_genero_decada

hdfs dfs -cat /datasets/synthea/resultados/pacientes_genero_decada/part-*

Secuencia de ejecución

El funcionamiento completo del ejercicio puede resumirse en las siguientes etapas:

  1. Se dispone del fichero patients.csv perteneciente al conjunto de datos Synthea.
  2. El fichero se encuentra almacenado en HDFS.
  3. Se preparan los programas mapper_pacientes.py y reducer_pacientes.py.
  4. Hadoop Streaming inicia el trabajo MapReduce.
  5. El Mapper lee los registros y genera pares clave-valor utilizando la década de nacimiento y el género.
  6. Hadoop realiza automáticamente las fases Shuffle y Sort, agrupando las claves iguales.
  7. El Reducer suma los valores correspondientes a cada grupo.
  8. El resultado se almacena nuevamente en HDFS.
  9. Finalmente, el estudiante puede consultar los resultados obtenidos.

Resultado del ejercicio

Como resultado del procesamiento se obtiene un listado con las diferentes combinaciones de género y década de nacimiento, junto con el número de pacientes correspondiente a cada grupo.

De esta forma, el estudiante puede comprobar de manera práctica cómo un conjunto de datos estructurado almacenado en HDFS puede ser procesado mediante un trabajo distribuido de MapReduce utilizando Hadoop Streaming y programas desarrollados en Python.
