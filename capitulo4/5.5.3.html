5.5.3. Ejercicio resuelto con Hadoop Streaming - Contador de palabras

En este ejercicio se continúa con la secuencia práctica desarrollada en las lecciones anteriores. Una vez cargados los documentos clínicos del corpus MEDDOCAN en el sistema de archivos distribuido HDFS, se utilizará Hadoop Streaming para ejecutar una tarea de procesamiento distribuido basada en el modelo MapReduce.

El objetivo es que el estudiante pueda comprender de forma práctica cómo Hadoop recibe un fichero almacenado en HDFS, distribuye su procesamiento y ejecuta dos programas desarrollados en Python: un programa Mapper y un programa Reducer.

La aplicación desarrollada corresponde al clásico problema de contador de palabras (WordCount). A partir de un documento médico del corpus MEDDOCAN se obtiene el número de veces que aparece cada palabra.

Objetivo del ejercicio

El objetivo principal consiste en cargar un fichero de texto en HDFS y ejecutar desde Jupyter Notebook un trabajo Hadoop Streaming que permita contar las apariciones de cada palabra.

  • Cargar un fichero MEDDOCAN en HDFS.
  • Crear un programa Mapper en Python.
  • Crear un programa Reducer en Python.
  • Ejecutar Hadoop Streaming.
  • Observar las fases Map, Shuffle y Reduce.
  • Consultar el resultado generado en HDFS.

Secuencia de ejecución

1. Comprobación de los ficheros MEDDOCAN

En primer lugar se comprueba que los ficheros del corpus MEDDOCAN están disponibles en el entorno de trabajo de Jupyter Notebook. Entre los ficheros disponibles se encuentra el documento meddocan_anonimizado.txt, así como diferentes documentos clínicos en formato TXT. :contentReference[oaicite:2]{index=2}

2. Carga del fichero en HDFS

El siguiente paso consiste en introducir uno de los documentos clínicos en el sistema de archivos distribuido HDFS. Para ello se utiliza el comando hdfs dfs -put. 

!hdfs dfs -put S0004-06142005001000011-4.txt /datasets/MEDDOCAN/
!hdfs dfs -ls /datasets/MEDDOCAN/

El segundo comando permite verificar que el fichero se encuentra correctamente almacenado en HDFS. En la ejecución realizada se comprueba la existencia del fichero con un tamaño de 2847 bytes. :contentReference[oaicite:3]{index=3}

3. Creación del programa Mapper

El Mapper constituye la primera fase del procesamiento MapReduce. Su función consiste en leer cada línea del documento, convertir su contenido a minúsculas, identificar las palabras y generar un par clave-valor formado por la palabra y el valor 1.

Por ejemplo, si el documento contiene la palabra paciente, el Mapper generará: 

paciente    1

El programa utilizado en el ejercicio es el siguiente: 

#!/usr/bin/env python3

import sys
import re

for line in sys.stdin:

    # Convertir a minúsculas y extraer palabras
    words = re.findall(r'\w+', line.lower())

    for word in words:

        print(f"{word}\t1")
El Mapper no realiza el cálculo final de las frecuencias. Simplemente transforma cada palabra encontrada en un par (palabra, 1). La agrupación de las palabras iguales será realizada posteriormente por Hadoop durante la fase Shuffle.

4. Creación del programa Reducer

El Reducer recibe los pares generados por el Mapper después de que Hadoop haya realizado automáticamente la fase de agrupación y ordenación denominada Shuffle.

Su función consiste en agrupar las apariciones de una misma palabra y sumar los valores asociados. 

#!/usr/bin/env python3

import sys

current_word = None
current_count = 0

for line in sys.stdin:

    word, count = line.strip().split("\t", 1)

    count = int(count)

    if current_word == word:

        current_count += count

    else:

        if current_word is not None:

            print(f"{current_word}\t{current_count}")

        current_word = word
        current_count = count


# Imprimir la última palabra
if current_word is not None:

    print(f"{current_word}\t{current_count}")

De esta forma, si el Mapper genera: 

hadoop    1
hadoop    1
hadoop    1

el Reducer devolverá: 

hadoop    3

5. Creación del script de ejecución WordCount

Para facilitar la ejecución del ejercicio se crea el script wordcount.py, que define las rutas de entrada y salida y lanza posteriormente el trabajo Hadoop Streaming. 

#!/bin/bash

INPUT=/datasets/MEDDOCAN
OUTPUT=/resultados/wordcount

# Eliminar salida anterior si existe
hdfs dfs -rm -r -f $OUTPUT

hadoop jar /usr/local/hadoop/share/hadoop/tools/lib/hadoop-streaming-3.4.0.jar \
    -files mapper.py,reducer.py \
    -input $INPUT \
    -output $OUTPUT \
    -mapper "python3 mapper.py" \
    -reducer "python3 reducer.py"

El script elimina previamente el directorio de resultados, evitando conflictos con ejecuciones anteriores, y posteriormente ejecuta Hadoop Streaming utilizando el fichero hadoop-streaming-3.4.0.jar.

6. Ejecución de Hadoop Streaming desde Jupyter Notebook

Una vez preparados el Mapper y el Reducer, se ejecuta el trabajo desde una celda de Jupyter Notebook. 

!hadoop jar /usr/local/hadoop/share/hadoop/tools/lib/hadoop-streaming-3.4.0.jar \
    -files mapper.py,reduce.py \
    -input /datasets/MEDDOCAN \
    -output /resultados/wordcount \
    -mapper "python3 mapper.py" \
    -reducer "python3 reduce.py"

Hadoop Streaming se encarga de distribuir el trabajo entre los nodos disponibles y coordinar las diferentes fases del procesamiento.

Fases del procesamiento MapReduce

Map

Lee el documento y genera pares (palabra, 1).

Shuffle

Hadoop agrupa y ordena automáticamente las palabras iguales.

Reduce

Suma las apariciones de cada palabra y genera el resultado final.

7. Resultado del procesamiento

Una vez finalizada la ejecución, Hadoop genera los resultados en el directorio: 

/resultados/wordcount

La ejecución realizada finalizó correctamente y Hadoop informó de la creación del directorio de salida. El trabajo utilizó 2 tareas Map y 1 tarea Reduce. Se procesaron 26 registros de entrada, generando 400 registros de salida del Mapper y 261 grupos de reducción, que finalmente produjeron 261 registros de salida. :contentReference[oaicite:4]{index=4}

8. Consulta de los resultados almacenados en HDFS

Finalmente se consulta el fichero generado por el Reducer mediante el comando hdfs dfs -cat: 

!hdfs dfs -cat /resultados/wordcount/part-00000

Este comando permite visualizar directamente desde Jupyter Notebook los resultados almacenados en HDFS.
